# 配置自动补全

High 与默认分支 nextgen 在加载和重载时自动补齐缺失配置：

- `config.yml`：使用当前分支内置默认文件和 `@ConfigData` 字段默认值。
- `worlds/*.yml`：每张地图使用 `worlds/world.yml` 模板，并保留原地图 ID、世界名与已有坐标。
- `custom.yml`：合并内置文件和程序默认值，保留自定义 MythicMobs、概率、权限和扩展配置分组。
- `tab.yml`：补齐程序默认值；High 还会合并内置 TAB 格式模板。
- 内嵌框架的 `AbstractYamlConfig`：保留原有补全功能，取消自动删除扩展键。

已有值（包括 `false`、`0`、空字符串、空列表）不会被默认值覆盖，列表不会逐项合并。不再自动运行 `custom.yml` 的未知键清理。没有规范默认值的空字段和自动坐标哨兵仍由原逻辑处理，不编造地图坐标。

YAML 语法错误或默认分组与用户值类型冲突会报出文件路径并中止该文件的升级，不把错误文件替换成默认文件。补全只修改本插件管理的配置文件，不处理其他插件配置和玩家数据库。MongoDB 缺省用户名和密码改为空，避免给原本无认证的配置补入 `admin`；已有认证配置保留。

修改格式或配置后使用 `/pit reload`。更换插件 JAR 应停服替换后完整重启。

自动化测试 `ConfigFilesTest` 覆盖嵌套补全、已有值保留、自定义分组保留、重复加载、地图模板、磁盘重载、字段默认值恢复，以及损坏文件不被覆盖。测试使用独立临时目录，不连接数据库。
