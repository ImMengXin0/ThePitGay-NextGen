# 寄存所、TAB 玩家条目与名牌更新

## 寄存所

旧实现仍使用 1.8 玻璃板损伤值 `15` 判断占位符。现代材料和物品组件不再按旧数据值区分颜色，这会影响空槽识别、计数和存取。

占位符改用黑色玻璃板与独立持久化标记，兼容旧白色/黑色储存格。占位符不计入物品数量、不写入实际物品存档。打开的容器通过 holder、档案归属和实际库存识别，避免其他插件的同名菜单被当作寄存箱。

左键或 Shift 点击物品存入/取出。转移依次填充兼容堆叠与空位，余量留在原槽位；背包仅使用 36 个存储格，保留物品寄存限制和其他监听器的取消状态。拖拽、数字键、双击收集、副手交换和丢弃操作被拦截。快照和恢复克隆物品，避免共享可变物品导致回滚失效。

7 项真实 Paper 库存回归覆盖旧占位迁移、存档往返、左右容器转移、满箱/满包余量、归属与标题校验、受限物品和取消事件，以及快照恢复。未连接实际玩家数据库。

## TAB 与 nametag 配置

编辑 `plugins/ThePitUltimate/tab.yml`，这是截图中玩家列表条目的格式设置。原有 `head`、`part`、`animation` 继续控制页眉页脚。

```yaml
player-list:
  enabled: true
  format: '{prefix}{name}{suffix} &8| &a%player_ping%ms'
nametag:
  enabled: true
  prefix: '{level} {rank-color}'
  suffix: ' &7%vault_prefix%{suffix}'
```

占位符：

| 变量 | 内容 |
| --- | --- |
| `{prefix}` | 原有等级/活动/连杀前缀 |
| `{suffix}` | 原有赞助星标、悬赏、活动后缀 |
| `{name}` | 昵称，未使用昵称时为玩家名 |
| `{level}` | 当前显示等级标签，尊重昵称等级 |
| `{rank-color}` | 玩家权限组颜色 |
| `%…%` | PlaceholderAPI 占位符，以被显示的玩家为对象 |

支持 `&` 颜色码，包括 PAPI 返回的颜色。PAPI 及所需扩展须已安装；没有 PAPI 时保留占位原文，其他格式照常更新。名牌由前缀、原版名字和后缀组成；TAB 条目使用完整自定义文本。默认格式保留活动、连杀和悬赏显示。

`/pit reload` 后格式在下一次名牌刷新（20 ticks）生效；旧版 16 字符前缀截断已移除。TAB 文本不变时不重复设置，保持每轮共享计算。`player-list.enabled` 与 `nametag.enabled` 可分别关闭；顶部 `enable` 控制原有页眉页脚任务。`tick`/`delay` 的调度间隔在完整重启后应用。
